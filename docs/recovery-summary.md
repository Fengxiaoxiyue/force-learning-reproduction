# 高成本恢复总结

本轮只针对初始训练效果较差的案例，固定保留所有失败尝试，不做只挑最佳种子的结果筛选。完整参数、运行时间和逐次诊断见 `docs/recovery-log.md` 与 `results/recovery/data/*.csv`。

| 案例 | 结论 | 关键结果 | 主要原因 |
|---|---|---|---|
| Figure 2A--C | 成功 | `N=1500`，MAE 0.00260，相关 0.99998 | `N=1000` 已学会轨道但相位漂移；扩容后锁相 |
| Figure 2E | 失败 | `N=2000` 测试 MAE 0.379 | 冻结闭环漂移；论文未公开 16 个系数 |
| Figure 2F | 波形成功、绝对相位部分成功 | 首末周期相关约 0.998 | 去噪与周期轨道稳定；全局相位仍偏移 |
| Figure 2H | 统计复现成功 | PSD 相关 0.973，标准差比 0.983 | 混沌轨迹不应以长时逐点相关判定 |
| Figure 2I fast | 成功 | `g=1.2`，MAE 0.0644，相关 0.992 | 降低混沌增益后快速轨道不再衰减 |
| Figure 2I slow | 失败 | 最佳振幅比 0.957，但频率为 1.333 倍 | 冻结闭环选中错误频率分支 |
| Figure 2J | 结构性成功 | MAE 0.00089，相关 0.999996 | 修复旧 `z` 误差与新 `r` 回归量错位一步的问题 |
| Figure 6A | 失败 | `N=1500` 测试 MAE 0.949 | 已修复延迟缓冲清零；非线性延迟闭环仍不稳定 |
| Figure 1B / 6B | 失败 | `N=1500` 测试 MAE 0.829 | 论文为 `N=20000`，每反馈单元抽样 500 个生成器神经元 |
| Figure 7B | 强结构性成功 | `N=1200`，均值 MAE 0.0747，相关 0.9735 | 修复静态输入和修改行协议；仍采用 shared-P 近似 |
| Supplement S1 | 冻结后失败 | 训练跟随，但多个种子冻结后频率/振幅失稳 | 标量 delta-rule 对吸引域和种子敏感；精确目标未公开 |

## 关键判断

1. 在线训练误差低不等于自治复现成功。Figure 2E、慢正弦、Figure 6A/6B 和 S1 都在冻结后离开目标轨道。
2. 增大 `N` 不保证单调改善。随机闭环系统可能随规模切换到不同频率分支，必须同时报告频率、振幅和首末周期指标。
3. Figure 2J 的主要问题是实现时序错误；Figure 7B 的主要问题是控制输入和内部修改协议错误。修复算法后，增加成本才有效。
4. Figure 2H 的长期逐点 MAE 不是合理成功标准。本轮新增短时、分布、功率谱和自相关指标。
5. Figure 6B 和精确 Figure 7B 仍受论文规模内存/计算约束；当前结果不能替代 `N=20000` 或每个修改行独立 RLS 的精确实验。
