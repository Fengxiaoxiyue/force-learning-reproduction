# CMU Motion Capture Inputs

Figure 8 uses the two trials named by Sussillo and Abbott (2009):

- `09_02.amc` for running.
- `08_01.amc` for walking.

Source: Carnegie Mellon University Graphics Lab Motion Capture Database,
https://mocap.cs.cmu.edu/

The database states that the data are free for research and commercial use,
but may not be directly resold. The requested acknowledgment is included in
the project report. These files contain joint-angle channels; global root
translation is removed by the preprocessing code.
