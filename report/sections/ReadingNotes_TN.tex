\subsection{Recommended execution order}
Run the tests first, then execute each case group independently:
\begin{verbatim}
matlab -batch "run('tests/run_all_tests.m')"
matlab -batch "run('scripts/run_figure2_suite.m')"
matlab -batch "run('scripts/run_figures3_to5.m')"
matlab -batch "run('scripts/run_figures6_to8.m')"
matlab -batch "run('scripts/run_supplement.m')"
\end{verbatim}
The full groups overwrite their own deterministic outputs. Compile this report from \texttt{report/} with \texttt{latexmk -pdf main.tex}. The generated report includes figures directly from \texttt{results/figures}, so no manual copying is required.
