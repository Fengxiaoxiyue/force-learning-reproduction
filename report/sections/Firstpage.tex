\begin{abstract}
This project reproduces a compact result from Sussillo and Abbott \cite{sussillo_generating_2009}: a chaotic recurrent rate network trained with FORCE learning to autonomously generate a periodic signal composed of four sinusoids. The main implementation follows the external feedback architecture in Figure 1A and the Figure 2D target function from the paper and its supplemental Matlab script. The reproduction code separates configuration, target generation, recursive least-squares updates, metrics, plotting, and tests so that the workflow is transparent and repeatable. A small all-to-all internal-learning extension is also included as a second-stage experiment.
\end{abstract}
